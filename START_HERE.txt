START HERE — BANK MARKETING ASSIGNMENT

1. Extract this ZIP.
2. Install: pip install -r requirements.txt
3. Open bank_marketing_classification.ipynb in Jupyter / VS Code.
4. Run all cells from top to bottom. The notebook downloads the public UCI data.
5. Check reports/model_comparison.csv for the actual six metrics for all five models.
6. Check reports/fit_diagnostics.csv and reports/winner.txt.
7. Run: streamlit run app.py
8. Upload test_data.csv and test all five models in the app.
9. Only after local validation, upload the project to your own GitHub and deploy.
10. Later, repeat the run in BITS Virtual Lab and take one genuine screenshot.

NOTE:
- 12,000 stratified records are sampled from the 45,211-row UCI bank-full dataset.
- `duration` is excluded to avoid using post-call information.
- Metrics and winner are deliberately not fabricated; they are generated by running the notebook.
- GitHub URL, deployed Streamlit URL and BITS Lab screenshot must be genuine.
