## a. Problem statement

A bank conducts direct-marketing campaigns to offer term deposits to customers. The objective is to classify whether a contacted customer will subscribe to the term deposit. This is a **binary classification** task:

- `no` (0): customer did not subscribe.
- `yes` (1): customer subscribed.

The positive class is `yes`. Since the target classes are imbalanced, the evaluation considers AUC, positive-class precision, recall, F1 and MCC in addition to accuracy.

## b. Dataset description

- **Source:** UCI Machine Learning Repository — Bank Marketing (`bank-full`).
- **Original size:** 45,211 records.
- **Original predictors:** 16, plus target `y`.
- **Instances used in this experiment:** 12,000 stratified records sampled from the original data (9,600 training / 2,400 test).
- **Predictors used:** 15. The feature `duration` is excluded because it is call duration and is not available before the call; including it would leak post-call information into the prediction.
- **Target:** `y` (`yes` / `no`).
- **Task:** binary classification.

The 15 predictor fields are `age`, `job`, `marital`, `education`, `default`, `balance`, `housing`, `loan`, `contact`, `day`, `month`, `campaign`, `pdays`, `previous`, and `poutcome`.

**Preprocessing:** numerical features are median-imputed and standardized; categorical features are imputed using the most frequent category and one-hot encoded. All transformations are inside the model pipelines and are fitted on training folds only. A stratified 80:20 train/test split is used with random state 42.
